# FILL AI — Дизайн-система: «Тетрадь · Линейка · Круги»

## 1. Концепция и философия
Интерфейс ощущается как живая школьная тетрадь, в которой лекция записывается сама в реальном времени. Никаких шаблонных градиентов, неоновых размытий, темных «космических» стеклянных плашек (AI-slop). 

Дизайн строится на принципах **нео-брутализма, тактильности и швейцарской сетки**:
- **Бумага и чернила**: теплая бумага в клетку (`#FBF7EA`), четкие чернильные контуры толщиной 2px (`#0E1A4B`), жесткие тени со смещением 4px / 8px без размытия.
- **Два режима**:
  - **«Тетрадь»** (светлый): основной режим для лендинга, авторизации, кабинета ученика и менеджера уроков.
  - **«Доска»** (темно-синий `#0B1440` с мелом `#F4F1E6`): режим аудиторной доски для кабинета преподавателя (студии прямого эфира).

## 2. Три сигнатуры бренда

### 1. Круги «FILL»
Механика заливки (от контура к цвету):
- **Логотип**: два пересекающихся круга (синий `#2340E0` и солнечный `#FFC72C`), в пересечении — бумажная линза с литерой **F**.
- **Кнопки**: при наведении круг заливки плавно разрастается из точки курсора или заливает фон.
- **Индикаторы и аватары**: круги с инициалами, круглые бейджи статистики.
- **Круговой Wipe**: переход между страницами через радиальное расширение круга клика (`clip-path: circle`).
- **Победа в квизе**: салют круглыми конфетти цветов солнца, неба и чернил.

### 2. Линейка (Ruler)
Настоящая измерительная линейка с миллиметровыми делениями и цифрами (`tabular-nums`):
- Разделитель секций на лендинге.
- **ScrollRuler**: тонкая линейка в шапке с желтым бегунком прогресса чтения страницы.
- **Таймлайн лекции**: хронометраж блоков конспекта у преподавателя и студента.
- **Шкала результатов квиза**: столбцы ответов аудитории «измеряются» по линейке.
- **Индикатор микрофона**: деления линейки прыгают в такт звуковой волне.

### 3. Школьные предметы и «Красная ручка»
- **SVG-набор графики**: циркуль, транспортир, угольник, колба, атом, ДНК, микроскоп, книга, карандаш, ластик, калькулятор, синусоида. Стиль: чернильный контур 2px со скруглёнными концами + смещенная подложка-круг (эффект типографской сбитой приводки).
- **Красная ручка учителя**:
  - Рукописные пометки шрифтом `Caveat` со стрелочками («тут формула!», «важно к экзамену»).
  - Волнистое подчеркивание ключевых слов (`RedPenUnderline`).
  - Круглые штампы **«ПРОВЕРЕНО»** и **«ДЕМО»** под наклоном −6°.

## 3. Дизайн-токены

### Цветовая палитра
```css
/* Бумага и чернила */
--color-paper:        #FBF7EA;  /* Фон тетради */
--color-paper-2:      #F2ECD6;  /* Вторая бумага, плашки карточек */
--color-ink:          #0E1A4B;  /* Основной текст, контуры 2px */
--color-grid:         #C7D6F2;  /* Тетрадная клетка и деления линейки */

/* Цвета бренда FILL */
--color-blue:         #2340E0;  /* Фирменный кобальтовый синий */
--color-sky:          #BBD4FF;  /* Мягкий небесный акцент */
--color-sun:          #FFC72C;  /* Солнечный желтый маркер */
--color-sun-soft:     #FFE9A3;  /* Подсветка полей и маркера */

/* Смысловые акценты */
--color-pen-red:      #E5383B;  /* Ошибки, правки, красная ручка */
--color-stamp-green:  #1F9D63;  /* Штамп «ПРОВЕРЕНО», верный ответ */

/* Режим «Доска» (кабинет преподавателя) */
--color-board:        #0B1440;  /* Темно-синяя доска */
--color-chalk:        #F4F1E6;  /* Меловой светлый текст */
```

### Жесткие тени и геометрия
```css
--shadow-hard:        4px 4px 0 0 var(--color-ink);
--shadow-hard-lg:     8px 8px 0 0 var(--color-ink);
--radius-card:        20px;
--radius-pill:        999px;
--border-ink:         2px solid var(--color-ink);
```

### Отступы и масштаб
Шкала кратности 4: `4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px, 96px`.
Все кнопки и интерактивные зоны на мобильных устройствах — не менее 44px.

## 4. Типографика

1. **Заголовки**: `Unbounded` (геометричный, широкий, выразительный). Поддержка кириллицы и казахских букв (`Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І`).
2. **Интерфейс и основной текст**: `Onest` (чистый, читаемый, нейтральный гротеск).
3. **Рукописные пометки (≤ 5% текста)**: `Caveat` (живой почерк преподавателя на полях).
4. **Линейки и таймеры**: `tabular-nums` для предотвращения скачков цифр.

Fluid-размеры заголовков через `clamp()`:
- `H1`: `clamp(2.5rem, 5vw + 1rem, 5.5rem)` (межстрочный 1.05–1.1)
- `H2`: `clamp(1.75rem, 3vw + 1rem, 3.25rem)` (межстрочный 1.15)
- `Body`: `1rem` / `1.125rem` (межстрочный 1.55)

## 5. Бан-лист (Строго запрещено)
- ❌ Никаких CSS-градиентов (`linear-gradient`, `radial-gradient`, классы Tailwind `bg-gradient-*`, `from-*`, `to-*`).
- ❌ Никаких размытий `blur-*`, `backdrop-blur`, glassmorphism, светящихся шаров.
- ❌ Никакого кислотно-зеленого `#AEDB00`, фиолетового, индиго.
- ❌ Никакого неконтролируемого использования моноширинного шрифта (`font-mono-tag`).
- ❌ Никаких стоковых фото Unsplash с поддельными отзывами.
- ❌ Никаких выдуманных цифр, поданных как доказанный факт (демо-данные помечаются как «цель пилота» или «демо-сценарий»).
- ❌ Никаких дефолтных серых компонентов shadcn.

## 6. Инвентарь компонентов

### Базовые примитивы
- `Logo`: два пересекающихся круга (синий и желтый) с линзой F.
- `Button`: тактильная кнопка с жесткой тенью 4px, нажатие со смещением `translate(4px, 4px)` и исчезновением тени.
- `Input`: тетрадная чернильная строка с желтой подсветкой маркера при фокусе и красной пометкой ошибок.
- `Card`: тетрадный лист (`#FBF7EA` или `#F2ECD6`) с контуром 2px и тенью `--shadow-hard`.
- `Chip` / `Tag`: скругленный бейдж-таблетка с чернильным контуром.
- `Stamp`: штамп «ПРОВЕРЕНО» (зеленый) или «ДЕМО» (красный) с наклоном −6° и пружинной анимацией.
- `Ruler`: шкала с миллиметровыми и сантиметровыми делениями.
- `ScrollRuler`: линейка в шапке с желтым ползунком прокрутки страницы.
- `CircleBadge`: круглый бейдж с метриками или инициалами.
- `NotebookBackground`: SVG-паттерн тетрадной клетки (`#C7D6F2`) с красным полем слева.
- `Marginalia`: рукописная пометка шрифтом Caveat со стрелочкой.
- `RedPenUnderline`: анимированное волнистое подчеркивание красной ручкой (`stroke-dashoffset`).
- `Icons`: собственный набор школьных SVG-предметов (циркуль, колба, атом, книга, микроскоп, ДНК и др.).
- `PageTransition`: переход между экранами круговой маской клика (`clip-path: circle`).

### Модули страниц
- `Header`: шапка-тетрадь, ScrollRuler, логотип, рабочие якоря, аватар-круг с корректными инициалами, переключатель «Тетрадь / Доска».
- `Auth`: единый компонент (`page` или `modal`), карточки-пропуска учителей и студентов Казахстана, 6-значный код в тетрадных клетках, валидация и шаг восстановления пароля.
- `LandingScreen`: разделен на независимые модули в каталоге `landing/`:
  - `Hero.tsx`: тетрадная композиция, рукописные пометки, интерактивные круги.
  - `Pipeline.tsx`: 3-шаговая прикрепленная сцена «Слово → Конспект (KaTeX) → Тест».
  - `Features.tsx`: разнокалиберный Bento-грид со школьными иллюстрациями.
  - `Audience.tsx`: выбор «Преподавателю» / «Ученику» с круговой заливкой.
  - `Pricing.tsx`: отрывные листы блокнота с перфорацией.
  - `Testimonials.tsx`: стикеры с честными пометками о пилоте.
  - `Faq.tsx`: аккордеон на строках тетради.
  - `FinalCta.tsx`: масштабный круговой CTA.
- `TeacherLiveScreen`: студия «Доска», таймлайн-линейка, квиз со шкалой делений, классный журнал посещаемости.
- `StudentScreen`: мобильный плеер «Тетрадь», рукописный конспект, вопрос-записка преподавателю, стикер «Что я пропустил?».
- `LessonsManager`: классный журнал уроков, зона-конверт для слайдов, индикатор бэкенда.

## 7. Принятые архитектурные решения
1. **Шрифты**: подключаются локально через пакеты `@fontsource/unbounded`, `@fontsource/onest`, `@fontsource/caveat` для быстрой гарантированной загрузки без внешних CDN.
2. **Сетка**: генерируется через чистый SVG `<pattern>` в компоненте `NotebookBackground`, без тяжелых фоновых изображений и без CSS-градиентов.
3. **Единые демо-пользователи**: вынесены в `frontend/src/data/demoUsers.ts` с реальными академическими организациями Казахстана (КазНУ, AITU, NU, Lingua Premier).
4. **Плавная анимация**: библиотека `framer-motion` для переходов и микро-взаимодействий, поддержка `prefers-reduced-motion` с автоматической деградацией в простое затухание (fade).
