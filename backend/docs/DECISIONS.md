# Реестр архитектурных и технических решений (DECISIONS.md)

Документ ведётся согласно правилам 2 и 3 раздела 0 ТЗ для фиксации принятых решений, значений по умолчанию, актуализации моделей, цен и версий SDK.

---

## 1. Выбор версий и окружения

- **Python:** 3.12 (используется базовый образ `python:3.12-slim`).
- **Фреймворк:** FastAPI >= 0.111.0, Pydantic v2 >= 2.7.0, SQLAlchemy 2.0 (asyncio) с драйвером `asyncpg`.
- **Миграции:** Alembic с поддержкой асинхронного движка.
- **Очереди и кэш:** Redis 7 (поддержка Streams, consumer groups и pub/sub).
- **Файловое хранилище:** S3-совместимое (MinIO локально в docker-compose, Cloudflare R2 / AWS S3 в проде). По умолчанию режим отдачи медиа `MEDIA_URL_MODE=proxy` для упрощения локальной разработки без проблем с невалидными внешними IP MinIO в presigned URL, с возможностью переключения в `signed`.

## 2. Модели и провайдеры ИИ (по состоянию на сентябрь 2026)

- **Анализ кадров (VLM):**
  - Основная: `gemini-3.5-flash-lite` (вход $0.30, выход $2.50 за 1M токенов).
  - Эскалация: `gemini-3.6-flash`.
  - Запасная: настраиваемый OpenAI-совместимый API (`VLM_FALLBACK_MODEL`).
  - Параметр `thinking_level`: `minimal` для кадров (согласно п. 4.2 ТЗ).
- **Генерация блоков конспекта, тест, отчёт (LLM):**
  - Основная: `gemini-3.6-flash` (вход $0.75, выход $3.75 за 1M токенов).
  - Запасная: `gemini-3.5-flash-lite` (с упрощённым промптом при таймаутах).
  - Параметр `thinking_level`: `low` для блоков конспекта, `medium` для тестов и отчёта.
- **ASR:**
  - Live: Soniox real-time WebSocket.
  - Offline: Soniox async REST.
  - Резерв: Groq Whisper Large v3 Turbo (чанки по 15-30 с).

## 3. Аутентификация и безопасность

- Внешний сервис аутентификации выдаёт JWT.
- Backend поддерживает:
  1. `HS256` по секрету (`JWT_SECRET`) для локальной разработки, интеграционных тестов и сред с общим секретом.
  2. `RS256` через `JWKS_URL` для боевой интеграции с IdP (Keycloak, Auth0, корпоративный SSO).
- В токене ожидаются claims:
  - `sub` (UUID пользователя).
  - `role` (`teacher` | `student` | `admin`).
  - `org_id` (UUID организации).
- Проверка прав выполняется на сервисном уровне и через FastAPI Dependencies (`require_role`, `verify_lesson_org`).

## 4. Гарантия порядка событий (`seq`)

- Для каждого урока ведется строго монотонная последовательность `seq`, начиная с 1.
- Выделение `seq` выполняется атомарно внутри транзакции Postgres:
  ```sql
  UPDATE lessons SET last_seq = last_seq + 1 WHERE id = :lesson_id RETURNING last_seq;
  ```
- Событие персистится в таблицу `lesson_events (lesson_id, seq, type, payload, created_at)`.
- После фиксации (COMMIT) транзакции событие публикуется в Redis pub/sub канал `pub:lesson:{id}`.
- Эфемерные события (например, `transcript.partial`) не имеют `seq`, не пишутся в БД и рассылаются только в Redis pub/sub.

## 5. Окна конспекта и финальный проход

- **Критерии закрытия окна**:
  1. Достижение целевого интервала 240 с с выравниванием на границу предложения или паузу ≥ 0.8 с.
  2. Смена темы слайда при длительности окна ≥ 120 с.
  3. Принудительное закрытие по достижении 360 с.
  4. Завершение урока (закрытие остаточного окна любой длительности).
- **Валидация ссылок на кадры**: Код (а не модель) валидирует, что все `frame_id` в `frame_refs` реально существуют в текущем окне и имеют статус `selected`.
- **Защита правок учителя**: Блоки с `edited_by_teacher=true` защищены от перезаписи финальным проходом.
- **Финальный проход**: генерирует TL;DR (3-5 предложений), оглавление, единый дедуплицированный глоссарий, выводы и домашнее задание с переводом урока в статус `ready`.

## 6. Обработка загруженных записей (Upload Flow)

- **Лимиты файлов**: максимальный размер файла 4 GB (`MAX_UPLOAD_SIZE_BYTES`), максимальная длительность медиа 4 часа (`MAX_UPLOAD_DURATION_SEC`).
- **Разрешенные форматы**: `mp4`, `mkv`, `webm`, `mp3`, `wav`, `m4a`, `mov`.
- **Presigned URLs**: генерация безопасных PUT-ссылок S3 со сроком жизни 1 час (3600 с).
- **Извлечение медиа**: двухконтурная стратегия:
  1. Использование системного `ffmpeg` / `ffprobe` в production/Docker окружении (`ffmpeg -vn -ac 1 -ar 16000 ...`).
  2. Fallback на OpenCV `cv2.VideoCapture` для прямого извлечения кадров при отсутствии бинарника `ffmpeg` в dev/test окружении.
- **Параллельная генерация блоков**: ограничение конкурентности пулом семафоров `FILE_PROCESSING_CONCURRENCY=4` для предотвращения перегрузки LLM API.

## 7. Тест, проверка ответов и аналитический отчёт

- **Генерация теста**:
  - Состав: 8-10 вопросов (по умолчанию 6 single, 2 multiple, 2 open).
  - Валидации в коде: 4 варианта ответов, проверка границ правильных индексов, триграммная дедупликация сходных формулировок, лимит не более 3 вопросов на один блок конспекта.
  - Двухпроходная верификация качества: Flash-Lite пытается ответить на вопрос по фрагменту конспекта. При расхождении ответов выставляется предупреждение `[⚠️ Требует проверки преподавателем]`.
  - Черновик создается со статусом `draft`, событие `quiz.ready` отправляется только преподавателю.
- **Проверка ответов**:
  - `single` и `multiple`: детерминированная проверка кодом без обращения к LLM.
  - `open`: проверка через Flash-Lite (`thinking_level=low`) с ограничением ответа 2000 символов и защитой от Prompt Injection (ответ подается как изолированные данные в тегах `<student_answer>`).
  - Преподаватель может корректировать баллы вручную (`graded_by='teacher'`).
- **Отчёт успеваемости**:
  - Точные числовые метрики (квартили, средний/медианный балл, процент по темам, список отстающих учеников с баллом < 50%) рассчитываются детерминированным Python-кодом.
  - LLM генерирует только текстовое резюме (narrative), проходящее валидацию регулярным выражением: все упоминаемые числа должны строго присутствовать во входной статистике `stats`.

## 8. Отказоустойчивость, лимиты и надёжность

- **Контроль бюджета урока**:
  - Потолок стоимости одного урока составляет `$3.00` (`MAX_COST_USD_PER_LESSON`).
  - Перед каждым обращением к Gemini проверяется суммарная стоимость в `lessons.cost_usd`.
  - При превышении порога система автоматически деградирует в экономичный режим: переключает генерацию на `gemini-3.5-flash-lite`, подавляет повторный анализ кадров и отправляет событие `error.notice` с кодом `budget_degraded`.
- **Очереди Redis Streams, XAUTOCLAIM и Dead Letter Queue (DLQ)**:
  - Обработка в группах `ai-workers` подтверждается `XACK` только после успешного коммита транзакции в БД.
  - Повисшие сообщения (без ACK более 90 с) периодически перехватываются через `XAUTOCLAIM`.
  - После 3 неудачных попыток доставки сообщение перемещается в `stream:dlq` с записью причины и отправкой `error.notice`.
  - При сбое генерации блока конспекта автоматически синтезируется резервный блок из транскрипта без кадров, гарантируя отсутствие смысловых провалов в конспекте.
- **Watchdog медиа-бота LiveKit**:
  - Бот отправляет heartbeat каждые 5 с в Redis с TTL=20 с.
  - При отсутствии heartbeat более 20 с в активном эфире супервизор считывает актуальное состояние урока из БД (последний `t_ms`, текущий индекс окна, последний pHash) и перезапускает бота через команду `restart` в `stream:bot-commands`.
- **Очистка устаревших данных (Retention)**:
  - Невыбранные кадры-кандидаты (`candidate`, `rejected`) и временные файлы старше `RAW_RETENTION_DAYS=30` удаляются регулярной фоновой задачей.
