# Fill AI Frontend

Современное клиентское веб-приложение для сервиса автоматических конспектов уроков **Fill AI**, разработанное на основе дизайн-системы и макетов `fillai-ui.html` с интеграцией с FastAPI бэкендом.

---

## 🎨 Дизайн-система и экраны

1. **Лендинг (`/`)**:
   - Презентация продукта: концепция живого конспекта без пост-обработки.
   - Схема конвейера (речь + слайды → структурированные блоки).
   - Интерактивный разбор ключевой функции «Как рождается живой вопрос».
   - Сравнение ценности для преподавателя и для учеников.
2. **Живой урок — Учитель (`live`)**:
   - Верхняя панель: статус урока, таймер, индикатор SSE-связи.
   - Интерактивный переключатель состояний ИИ (`listen`, `process`, `question`, `results`, `attention`).
   - Потоковый рендер конспекта с коллаутами (`определение`, `пример`), математическими формулами и интерактивными кадрами со слайдами и номерными бейджами.
   - Сворачиваемая плашка живого транскрипта с анимацией печати.
3. **Вид ученика (`student`)**:
   - Эмулятор смартфона с переключением состояний: «Ожидание», «Конспект (только чтение)», «Экспресс-опрос».
   - Интерактивная карточка ответа на вопрос в реальном времени.
4. **Бэкенд-панель (`manager`)**:
   - Мониторинг здоровья FastAPI бэкенда (`http://localhost:8000/readyz`).
   - Создание реальных уроков (`POST /v1/lessons`) для LiveKit WebRTC или S3 Upload.
   - Управление сессией (старт, стоп) и экспорт конспекта в чистый Markdown.

---

## 🛠 Технологический стек

- **Сборщик / Среда**: Vite + React 18 + TypeScript.
- **Стилизация**: Tailwind CSS + кастомные токены из `fillai-ui.html` (`--bg`, `--surface`, `--blue`, `--green`).
- **Шрифты**: Google Fonts `Manrope` (заголовки) и `IBM Plex Sans` (текст).
- **Иконки**: Lucide React.
- **Сетевой уровень**:
  - `apiClient`: Типизированный REST-клиент с обработкой ошибок RFC 7807 (`application/problem+json`).
  - `LessonSSEClient`: Автономный менеджер SSE-подключения с компенсацией пропущенных сообщений (`after_seq`) и автореконнектом.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
cd frontend
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу: `http://localhost:3000`.

Vite настроен с автоматическим проксированием запросов к `/v1`, `/readyz` и `/healthz` на локальный FastAPI бэкенд (`http://localhost:8000`).

### 3. Сборка для production
```bash
npm run build
```
Собранные статические файлы будут сохранены в папке `dist/`.
